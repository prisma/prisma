More Prisma 7 projects can move to Prisma 8

A Prisma 7 project that…now
has Unsupported("tsvector") fieldsloads; each field is a raw column

Prisma 8 taking over migrations in a Prisma 7 project is now 6 of 7 done. The last gap: the datasource’s extensions list.

The handover means Prisma 8 owns migrations while the project still reads schema.prisma. The referential action and primary key fixes merged this morning, Thursday.

Breaking changes that landed

A client takes its contract as a typed value

postgres<Contract>({ contractJson })

postgres({ contract: contractFromJson<Contract>(json) })

A value the client generates is @onCreate; @default means the database

id String @id @default(uuid())

id String @id @onCreate(uuid())

Type aliases replace field presets

An alias can carry @onCreate and @onUpdate, and the contract stores the real column type. Postgres, SQLite and MongoDB ship temporal.CreatedAt and temporal.UpdatedAt. Removing the presets is next.

The first two merged on Monday and Tuesday. Field presets still work until the third and last slice of TML-3607 removes them.

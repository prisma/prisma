Local emulators, from one command

prisma dev --detach start the app, return once it answers

prisma dev url print a local service’s URL

prisma dev stop stop what this folder started

prisma emulator list list the running emulators

Each folder gets its own services, ports and databases. Released this week: Prisma ORM 8.0.0-rc.19, prisma 8.0.0-rc.24 and rc.25, Composer 0.31, 0.32 and 0.33.

The docs now tell people to ask prisma dev url for a local URL instead of hard-coding ports, and the getting-started eval follows them.

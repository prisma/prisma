Foundations and breaking changes

  • One CLI and one config file8 Octprisma is the only CLI. Composer's settings live in prisma.config.ts.
  • SQL expression literals12 OctRaw SQL is written sql`…` in PSL, in TypeScript contracts and in migration files.
  • @noCheck removed16 OctA list that allows null elements is written T?[].

Upgrade path from Prisma 7

  • Storage a model does not map13 OctA table can hold columns no model maps, and a table can have no model. Prisma 7's @ignore keeps working. ADR 267.

Docs and the new user's first hour

  • Docs stop naming prisma-composer8 OctThe docs and the shipped skill name one CLI.

Query features

  • Row locking on a select7 OctforUpdate, forNoKeyUpdate, forShare and forKeyShare in the SQL builder and the ORM. ADR 261.
  • Design for leaving fields out7 OctThe Prisma 8 replacement for omit is designed.
  • firstOrThrow on collections8 OctIn the SQL and MongoDB ORMs.
  • variant()6 OctSelects rows by discriminator value.
  • The Postgres driver returns text6 OctEvery column arrives as server text, so a codec decodes it once.
  • Collection classes, scopes and query fragments15 OctA custom collection keeps its class through a chain. Queries can name a weighted full-text index. Packages can add collection methods.
Inside the projects still in progress

Big parts that merged

  • Data types own column types3 of 6Contract columns store a data type id, with an upgrade script. contract infer reads column types from data types, and Unsupported(...) is gone.
  • Migration statements4 of 7migration plan and db update refuse to lose data until you answer with --delete or --rename. --convert and --backfill work on Postgres and SQLite. MongoDB renames and deletes too.
  • PSL mixins4 of 5Mixins are built, with editor support. Removing field presets is left.
  • Prisma 7 handover3 of 7Prisma 8 takes over migrations while Prisma 7 keeps serving queries. No baseline command is needed.
  • Columns with no codec0 of 2Designed as raw columns in ADR 273. Slice 1 is built and reviewed.
  • Emulator controls3 of 5Composer has prisma dev --detach, prisma dev stop, prisma dev url and prisma emulator list. Each checkout gets its own services and ports.
  • Language server2 of 4Hover, go to definition, find references and rename all merged.
  • Middleware sees a tree of activities3 of 5Statements, transactions and client calls are activities that middleware can observe or answer. ADR 271.
  • Nested writes0 of 5Every top-level write now runs through one mutation graph, the base for nested update, delete and upsert.

# Brief: D5 — `aggregateTypes` emission

## Task

Give SQL `TypeMaps` its seventh key, `aggregateTypes`, generated by the contract emitter from the same aggregate descriptor contributions the runtime registry resolves against — so emitted types and runtime decoding share one source and cannot disagree. The emitter reads the declarative descriptor half from the control stack (the framework-side vocabulary D2 placed there for exactly this consumer); the emitted map must carry enough structure for the ORM (D6) to derive aggregate availability and result types with the same exact-over-trait-over-any precedence the runtime uses: per operation, the exact codec overloads, the trait fallbacks, the input-agnostic entry, and each row's output codec ref and nullability. The contract shape test covers the new key; all affected fixtures are regenerated with every movement attributable to the new key; serialized `contract.json` does not move (the surface is type-only in `contract.d.ts` — verify rather than assume).

**Binding constraint (D4 review):** emission resolves against the CONTRIBUTED codec set, never the target registry. The SQLite adapter contributes 9 of the target's 11 codecs (its `renderOutputType` filter drops `sql/char@1`/`sql/varchar@1`, documented at `descriptor-meta.ts:4-8`); PostgreSQL contributes unfiltered. Deriving `aggregateTypes` from the target registry would emit SQLite availability the runtime won't honour — the exact types-vs-runtime divergence this slice exists to close. A test must pin this: the emitted SQLite map carries no trait-served row for a codec the adapter does not contribute.

## Scope

**In:** `TypeMaps` in `packages/2-sql/1-core/contract/src/types.ts` (seventh generic + key); the emitter's `aggregateTypes` generation (`packages/1-framework/3-tooling/emitter/src/generate-contract-dts.ts` and whatever SQL-side contribution the emitter consumes); the contract shape test (`packages/2-sql/1-core/contract/test/contract-typemaps-shape.test.ts`); fixture regeneration across committed contracts.

**Out:** any consumer of the emitted map (D6 owns ORM availability/result-type resolution); the runtime registry (done, D2/D3); SQLite descriptors (D4 — if D4 has not yet merged its matrix when you run, emit from whatever descriptors the composed stack carries and note it; the emission machinery must be matrix-agnostic either way); Mongo `TypeMaps`.
